# Portfolio Website

A fully responsive, production-ready personal portfolio website built with semantic HTML5, modern CSS (using fluid typography, custom properties, and grid layouts), and lightweight vanilla JavaScript. Designed to highlight technical expertise in digital analytics implementation, data engineering, and data visualization.

## 🚀 Features

* **Fully Responsive Layout:** Optimized for all screen sizes—from mobile phones and foldables to tablets and high-res widescreen desktops.
* **Dynamic Pipeline Animation:** Features a visual data pipeline (Interaction $\rightarrow$ Data Layer $\rightarrow$ Tag Manager $\rightarrow$ Warehouse $\rightarrow$ Reporting) that dynamically scales and switches orientation (horizontal to vertical) on smaller viewports.
* **Interactive Code Console:** A simulated sandbox terminal showcasing real tracking calls (`utag.link()`).
* **Automated Tenure Counter:** A script that automatically calculates and displays your current professional tenure in real-time.
* **Scroll Progress Indicator:** A smooth-gradient top progress bar reflecting the user's scroll depth.
* **Intersection Observer Animations:** Staggered, performance-conscious fade-up reveal animations for content sections (respects `prefers-reduced-motion`).
* **Zero External Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript—no heavy frameworks or build steps required.

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic elements, ARIA attributes, meta tags for SEO/OpenGraph)
* **Styling:** CSS3 (Custom Properties, CSS Grid, Flexbox, `clamp()` fluid typography, and Aurora background gradients)
* **Scripting:** Vanilla JavaScript (ES6+ Intersection Observers, dynamic date calculations, scroll listeners)
* **Fonts:** Google Fonts (*Bricolage Grotesque*, *IBM Plex Sans*, *IBM Plex Mono*)
